# Redes Neuronales V - Redes Siamesas

## Descripción

Este proyecto desarrolla una práctica de reconocimiento y verificación facial mediante Redes Neuronales Siamesas, utilizando técnicas de Deep Learning para comparar imágenes y generar embeddings faciales.

## Objetivo

Implementar una red neuronal siamesa utilizando TensorFlow y Keras, aplicando preprocesamiento de imágenes, Triplet Loss y técnicas de comparación de características.

## Tecnologías utilizadas

- Python
- Google Colab
- TensorFlow
- Keras
- OpenCV
- NumPy
- Matplotlib
- Scikit-learn

## Contenido

- Preprocesamiento de imágenes faciales.
- Construcción de la arquitectura siamesa.
- Implementación de Triplet Loss.
- Entrenamiento y evaluación del modelo.
- Comparación de embeddings faciales.
- Visualización de resultados.

## Desarrollo

La implementación y las pruebas se encuentran documentadas en el notebook de Google Colab incluido en este repositorio.
